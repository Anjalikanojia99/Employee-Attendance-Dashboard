# Employee Attendance Analysis Dashboard

📊 Project Overview
A Power BI dashboard designed to track and analyze employee attendance. It provides a clear view of working days, attendance percentage, present/absent/leave status, and daily attendance trends through interactive visuals and employee-level details.

🛠️ Tech Stacks - Tools & Technologies 
Power BI – Dashboard development and visualization
Power Query – Data cleaning and transformation
DAX – Measures, KPIs, and calculations
Data Modeling – Relationships between attendance and supporting tables
Excel/CSV – Source data

🔄 Data Preparation
The dataset was prepared using Power Query before building the dashboard.

Key transformation steps included:

Removing unnecessary columns
Handling missing and inconsistent values
Correcting data types
Creating date-related columns
Creating Day of Week information
Creating weekday numbering for proper sorting
Preparing the data for analysis and visualization

📌 Key Features
👥 Employee-wise Attendance Tracking
📅 Daily & Monthly Attendance Analysis
📊 Attendance Percentage & KPIs
🟢 Present / Sick / Vacation / On-Call Status
🗓️ Working Days & Total Days Tracking
📈 Daily Attendance Trends
🔎 Interactive Employee & Month Filters
📋 Calendar-based Attendance View
